# 智能客服使用指南

> 本文档适用于 SheepAI Mall 平台官方客服知识库，帮助用户用好智能客服（AI 客服 + 人工客服）。

## 一、入口

- 网站**右下角悬浮机器人按钮**：点击进入客服对话（首页、购物车、个人中心等页面均可看到）。
- 商品详情页/店铺页的"联系客服"入口：直接进入对应商家或平台客服。

## 二、智能客服能做什么

| 能力 | 用法示例 |
|------|----------|
| 商品咨询/推荐 | "有什么蓝牙耳机？""这款手机有什么规格、多少钱？"（会以商品卡片展示） |
| 卡片下单 | 点击商品卡片上的"购买"→ 选规格数量 → 选收货地址 → 确认后生成待支付订单 |
| 加入购物车 | 点击商品卡片"加入购物车"→ 选规格数量 → 确认后加购 |
| 订单查询 | "我的订单到哪了？"（展示订单卡片，点击查看详情） |
| 申请售后 | "我要退货/退款/换货" → 点击订单卡片"申请售后"→ 选类型填原因 → 确认提交 |
| 改地址/取消订单 | 说出需求 → 核对**确认卡**信息 → 点"确认执行"后生效 |
| 查购物车 | "购物车里有什么？" |
| 政策问答 | 退货政策、发货时效、运费规则等（基于平台知识库作答） |
| 转人工 | 点击对话区"转人工"按钮，或直接在消息里说"转人工/人工客服" |

## 三、重要交互说明：确认卡

- 涉及实际操作的请求（下单、加购、改地址、取消订单、申请售后），客服不会直接执行，会生成一张**待确认操作卡**。
- 请核对卡片上的信息（商品、规格、数量、地址、金额），点击"确认执行"才真正生效；点"取消"则放弃。
- 确认卡几分钟内有效，过期需重新发起。

## 四、AI 客服与人工客服

- 部分会话由 AI 自动接待，部分由人工客服接待（取决于平台与商家开关设置）。
- 人工服务中 AI 暂停应答，由坐席手动回复；超时未接入会自动转回 AI。
- 商家客服会话只处理该商家商品与订单相关问题；商家未开通智能客服时会自动接入平台官方客服。

## 五、常见问题

**Q：客服答非所问？**
A：尽量描述具体场景（商品名、订单号、问题现象）；也可直接说"转人工"。

**Q：为什么让我点卡片按钮，而不是直接帮我操作？**
A：涉及下单、付款、售后等敏感操作，必须由你本人点击确认，保障账户安全；客服只负责把信息和入口准备好。

**Q：聊天记录会丢吗？**
A：聊天记录长期保留，进入客服页自动加载历史对话，向上滚动可查看更早内容。

**Q：客服咨询收费吗？**
A：对用户完全免费。
