# 平台购物与支付指南

> 本文档适用于 SheepAI Mall 平台官方客服知识库，帮助用户了解从找商品到完成支付的全流程。

## 一、购物流程

1. **找商品**：首页浏览分类，或使用顶部搜索框输入关键词（如"蓝牙耳机"）。
2. **看详情**：点击商品进入详情页，可查看价格、规格、库存、商品评价。
3. **选规格**：多规格商品需先选择规格（颜色/容量等），缺货规格不可选。
4. **下单**：两种方式——
   - 商品详情页"立即购买"；
   - 加入购物车后从购物车勾选结算。
5. **确认订单**：核对收货地址（可新增或切换默认地址）、商品与金额，提交生成**待支付订单**。
6. **支付**：提交后请在订单有效期内完成支付。

## 二、支付方式

- **微信支付**：调起微信完成支付，支付成功后订单进入"待发货"。
- **模拟支付（测试环境）**：开发/演示环境提供的模拟支付入口，点击即视为支付成功。

## 三、订单状态说明

| 状态 | 含义 | 可操作 |
|------|------|--------|
| 待支付 | 订单已创建未完成付款 | 立即付款 / 取消订单 |
| 待发货 | 已付款，商家备货中 | 仅退款（售后） |
| 待收货 | 商家已发货 | 查看物流 / 确认收货 / 退货退款 / 换货 |
| 已完成 | 已确认收货 | 评价 / 退货退款 / 换货 |
| 已取消 | 订单已取消（仅待支付可取消） | 查看详情 |

## 四、常见问题

**Q：下单后在哪里付款？**
A：我的 → 我的订单 → 待付款，点击"立即付款"。也可以让智能客服帮你，在客服对话中说出需求，客服会展示商品卡片，点击"购买"按提示完成。

**Q：待支付订单多久会取消？**
A：请尽快完成支付；长时间未支付的订单会被系统自动取消，取消后需重新下单。

**Q：拍错了怎么取消？**
A：仅"待支付"状态可取消（订单列表点"取消订单"）。已付款订单如需取消，请申请"仅退款"售后。

**Q：可以修改订单中的商品或数量吗？**
A：订单提交后不可修改，请取消后重新下单（已付款订单走售后流程）。

**Q：一个订单可以包含多个商家的商品吗？**
A：不可以。订单归属单一商家，购物车中不同商家的商品需分别结算。
