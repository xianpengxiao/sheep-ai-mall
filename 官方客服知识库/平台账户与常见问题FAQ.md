# 平台账户与常见问题 FAQ

> 本文档适用于 SheepAI Mall 平台官方客服知识库，覆盖账户、入口导航与高频问题。

## 一、账户相关

**Q：如何注册/登录？**
A：点击"我的"页面，使用手机号注册并登录；登录后可购物、查订单、使用客服。

**Q：忘记密码怎么办？**
A：登录页选择找回密码，按短信验证码重置。

**Q：如何修改手机号/头像等资料？**
A：我的 → 个人资料/设置中修改。

**Q：收货地址在哪里管理？**
A：我的 → 收货地址，可新增、编辑、删除、设置默认地址。

## 二、入口导航

| 功能 | 入口 |
|------|------|
| 我的订单 / 退款售后 | 我的 → 我的订单（顶部"退款/售后"入口） |
| 购物车 | 底部导航"购物车" |
| 收货地址 | 我的 → 收货地址 |
| 官方智能客服 | 右下角悬浮机器人 |
| 商家客服 | 店铺页/商品详情页"联系客服" |
| 商家中心 | 我的 → 商家中心（商家账号可见，含店铺管理、客服坐席、售后管理、资金管理） |
| 管理中心 | 我的 → 管理中心（平台管理员可见） |

## 三、高频问题

**Q：为什么手机端登录后看不到商家中心/管理中心？**
A：请使用对应身份的账号登录：商家账号（入驻成功的商家）显示商家中心；平台管理员账号显示管理中心。

**Q：如何成为商家开店？**
A：我的 → 商家中心 → 申请入驻，提交资质资料，平台审核通过后即可发布商品。

**Q：平台上的商品都是平台卖的吗？**
A：不是。平台由入驻商家经营各自店铺；商品详情页与订单可查看归属商家。商家店铺页的客服即该商家专属客服。

**Q：支付安全吗？**
A：支付由微信支付通道完成，平台不保存银行卡信息；退款原路退回支付账户。

**Q：遇到问题人工介入的渠道？**
A：客服对话中点击"转人工"或发送"人工客服"；售后被拒或有争议时说明情况，人工客服协助跟进。

**Q：如何评价商品？**
A：订单"已完成"后在订单列表点击"评价"；评价后可查看/隐藏。
