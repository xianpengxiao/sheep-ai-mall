## 📖 项目介绍

### 项目定位

SheepAI Mall 是一个面向中小商家的智能电商后端系统，提供从商品管理、订单处理、支付对接、搜索引擎到资金结算的全链路电商能力。

### 开发背景

市面上成熟的电商系统功能臃肿、二次开发成本高，而轻量级的解决方案又往往缺少 AI、搜索、RBAC 权限等现代化能力。本项目旨在提供一个**模块清晰、易扩展、开箱即用**的电商后端。

### 实现目标

- 提供标准化的商品 → 下单 → 支付 → 评价 → 结算全流程
- 接入 AI 大模型自动生成商品标题、描述和营销文案
- 基于 Elasticsearch + IK 分词器实现高效商品搜索
- 支持商家入驻、多角色 RBAC 权限管理
- Docker 一键部署，降低运维成本

## ✨ 核心功能模块

### 1. AI 商品文案生成（亮点功能）
- 接入 DeepSeek 大模型，根据商品核心卖点自动生成：
  - `title` — 15 字以内吸睛标题
  - `detail` — 200-300 字场景化描述文案
  - `sellPoints` — 5 条精炼卖点
- 采用结构化 JSON 输出，直接填充商品表单
- 生成记录持久化，支持失败重试

### 2. 商品管理
- SPU + SKU 多规格商品模型
- 商品上下架、审核流程
- 敏感词自动检测过滤
- 商品分类树（无限级）
- AI 一键生成商品文案

### 3. 订单系统
- 订单生命周期：待支付 → 已支付 → 已发货 → 已完成 → 已取消
- **RabbitMQ 异步库存锁定/释放**，保证高并发下库存准确性
- Redis 幂等去重 + 分布式锁防止超卖
- 支付超时自动取消（定时任务 + 消息队列双保障）
- 订单自动完成（收货后定时触发）

### 4. 搜索系统（ES）
- 商品多字段匹配（名称、副标题、品牌）+ 权重提升
- IK 分词器中文分词 + Wildcard 单字兜底
- 搜索结果高亮展示
- 商家搜索（店铺名称/简介/经营范围）
- 全量同步 API + 条件加载（ES 不可用时自动降级）

### 5. RBAC 权限体系
- JWT 无状态认证（Token 签发 + Redis 黑名单）
- 角色：超级管理员 / 运营人员 / 只读用户 / 商家
- 细粒度权限标识如 `spu:create`、`order:list`、`merchant:audit`
- AuthInterceptor 拦截器统一校验，ThreadLocal 传递用户上下文

### 6. 商家系统（三种视角隔离）

| 视角 | 说明 |
|------|------|
| **买家端** | 浏览商家详情、商品列表、评价 |
| **商家后台** | 商品管理、订单管理、营收统计、评价管理 |
| **平台管理** | 入驻审核、信息变更审核、商家禁用 |

- Cashier 模式：所有查询通过 `merchant_id` 硬隔离
- 店铺信息变更审核流程（修改后需平台审核）

### 7. 资金管理
- 商家结算账户绑定（目前项目暂未正式上线，当前只是功能展示，没有开通真实支付渠道）
- 类目佣金规则配置
- 订单分佣自动计算
- 商家提现申请 + 管理员审核打款
- 资金流水记录（含余额变动追踪）

### 8. DSR 评分体系
- 商品评价三维评分：描述相符、服务态度、物流服务
- 每日定时汇总商家近 90 天评分
- 过期评价自动隐藏

### 9. 用户系统
- 手机号 / 邮箱注册
- 手机号 / 邮箱验证码发送（腾讯云短信 / QQ邮箱 SMTP）
- 个人资料完善（实名认证、昵称、头像）
- 手机号 / 邮箱安全换绑（双验证码校验）
- 密码重置（免旧密码验证码模式）
