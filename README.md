## 📖 项目介绍

### 项目定位

SheepAI Mall 是一个面向中小商家的智能电商后端系统，提供从商品管理、订单处理、支付对接、搜索引擎、资金结算到 **AI 智能客服与售后处理** 的全链路电商能力。

### 开发背景

市面上成熟的电商系统功能臃肿、二次开发成本高，而轻量级的解决方案又往往缺少 AI、搜索、RBAC 权限等现代化能力。本项目旨在提供一个**模块清晰、易扩展、开箱即用**的电商后端。

### 实现目标

- 提供标准化的商品 → 下单 → 支付 → 评价 → 结算全流程
- 接入 AI 大模型自动生成商品标题、描述和营销文案
- **AI 客服 Agent**：意图识别 + 工具调用 + RAG 检索，对话内完成商品卡片下单、售后申请等业务办理
- 基于 Elasticsearch + IK 分词器实现高效商品搜索（同时作为客服 Agent 的商品检索引擎）
- 完整的售后链路：用户申请 → 商家处理 → 退款联动（微信支付原路退回）
- 支持商家入驻、多角色 RBAC 权限管理
- Docker 一键部署，降低运维成本

## ✨ 核心功能模块

### 1. 智能客服 Agent（亮点功能）
- **Agent 架构**：意图门禁 → 额度检查 → LLM（系统提示词 + 用户画像 + RAG + 工具调用）→ 流式 SSE 下发
- **只读工具**：订单查询、商品搜索（ES 优先 + DB 拆词兜底）、规格/库存查询、购物车、收货地址
- **确认闸写操作**：下单/加购/改地址/取消订单/申请售后**只生成待确认操作单**，用户点击确认卡后才执行，参数以服务端快照为准，全程幂等
- **卡片化交易**：商品卡片"购买"（规格+数量+地址弹层）/ 订单卡片"申请售后"（类型按订单状态收敛），卡片与操作单随消息持久化、刷新恢复、状态回查
- **时间分层上下文**：近 2 小时消息全文注入，更早按天保留样例（带日期标记），兼顾连续追问与长话题感知
- **AI/人工双轨**：平台/商家/单会话三级开关，默认人工，商家开通后手动开启 AI；坐席控制台双向转接
- **额度与限流**：商家月度 Token 总量管控 + 分钟级限流，耗尽自动转人工
- 详细能力见 [客服Agent能力清单.md](客服Agent能力清单.md)

### 2. RAG 知识库
- 平台 + 商家两级知识库，向量表按商家隔离（每商家独立表）
- 支持 md 文件上传与手工录入，服务端剥离 Markdown 排版符号后分块嵌入
- 检索按会话归属自动路由平台/商家库，结果注入 System Prompt 据文作答
- 嵌入链路含 ASCII 安全重写拦截器（兼容工作区网关），嵌入失败原因可见
- 平台侧知识文档见 [官方客服知识库/](官方客服知识库/)

### 3. 售后全链路
- **用户申请**：订单页/客服卡片双入口，类型按订单状态收敛（待发货=仅退款；待收货/已完成=退货退款/换货，已完成不限时）
- **商家处理**：商家中心"售后管理"同意/拒绝；**同意退款类即联动**——微信支付 V3 原路退款（模拟支付本地到账）+ `refund_deduct` 流水扣商家余额 + 订单退款标记，全程事务、幂等防重
- **防重设计**：商家处理原子抢占 + 退款记录唯一校验 + 申请并发锁，杜绝重复退款/重复提交

### 4. AI 商品文案生成
- 接入 DeepSeek 大模型，根据商品核心卖点自动生成：
  - `title` — 15 字以内吸睛标题
  - `detail` — 200-300 字场景化描述文案
  - `sellPoints` — 5 条精炼卖点
- 采用结构化 JSON 输出，直接填充商品表单
- 生成记录持久化，支持失败重试

### 5. 商品管理
- SPU + SKU 多规格商品模型
- 商品上下架、审核流程
- 敏感词自动检测过滤
- 商品分类树（无限级）
- AI 一键生成商品文案

### 6. 订单系统
- 订单生命周期：待支付 → 待发货 → 待收货 → 已完成 / 已取消
- **RabbitMQ 异步库存锁定/释放**，保证高并发下库存准确性
- Redis 幂等去重 + 分布式锁防止超卖
- 支付超时自动取消（定时任务 + 消息队列双保障）
- 订单自动完成（收货后定时触发）+ 分佣结算

### 7. 搜索系统（ES）
- 商品多字段匹配（名称、副标题、描述、品牌）+ 权重提升
- IK 分词器中文分词 + Wildcard 单字兜底
- 搜索结果高亮展示
- 商家搜索（店铺名称/简介/经营范围）
- 全量同步 API + 条件加载（ES 不可用时自动降级）
- 客服 Agent 商品搜索复用同一索引（含商家范围过滤）

### 8. RBAC 权限体系
- JWT 无状态认证（Token 签发 + Redis 黑名单）
- 角色：超级管理员 / 运营人员 / 只读用户 / 商家
- 细粒度权限标识如 `spu:create`、`order:list`、`merchant:audit`
- AuthInterceptor 拦截器统一校验，ThreadLocal 传递用户上下文

### 9. 商家系统（三种视角隔离）

| 视角 | 说明 |
|------|------|
| **买家端** | 浏览商家详情、商品列表、评价 |
| **商家后台** | 商品管理、订单管理、客服坐席、**售后管理**、营收统计、评价管理 |
| **平台管理** | 入驻审核、信息变更审核、商家禁用、客服工作台 |

- Cashier 模式：所有查询通过 `merchant_id` 硬隔离
- 店铺信息变更审核流程（修改后需平台审核）

### 10. 资金管理
- 商家结算账户绑定（目前项目暂未正式上线，当前只是功能展示，没有开通真实支付渠道）
- 类目佣金规则配置
- 订单分佣自动计算
- 商家提现申请 + 管理员审核打款
- 资金流水记录（含余额变动追踪、售后退款扣回）

### 11. DSR 评分体系
- 商品评价三维评分：描述相符、服务态度、物流服务
- 每日定时汇总商家近 90 天评分
- 过期评价自动隐藏

### 12. 用户系统
- 手机号 / 邮箱注册
- 手机号 / 邮箱验证码发送（腾讯云短信 / QQ邮箱 SMTP）
- 个人资料完善（实名认证、昵称、头像）
- 手机号 / 邮箱安全换绑（双验证码校验）
- 密码重置（免旧密码验证码模式）
